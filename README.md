# 👕 Gestión de Ropa y Productos

¡Bienvenido al **Sistema de Gestión de Ropa y Productos**! Esta es una aplicación web moderna, rápida y elegante diseñada para ayudarte a organizar tu inventario de prendas de vestir y exportar la información directamente a archivos Excel profesionales.

![Mockup del Sistema](file:///C:/Users/Rodrigo/.gemini/antigravity/brain/4edaf646-88e9-48cc-8033-1beff824033f/gestion_ropa_mockup_1778690247801.png)

## ✨ Características Principales

- **Registro Detallado**: Agrega productos con nombre, categoría, talla, color, precio, stock y descripción.
- **Gestión de Fotos**: Permite registrar el nombre del archivo de imagen para cada producto.
- **Listado Dinámico**: Visualiza todos tus productos en una tabla interactiva con acciones rápidas (como eliminar ítems).
- **Exportación Inteligente a Excel**: Genera un archivo `.xlsx` automáticamente.
  - **Organización por Hojas**: El sistema agrupa los productos por categoría y crea una pestaña diferente en Excel para cada una (ej: una hoja para "Pantalones", otra para "Remeras").
- **Diseño Premium**: Interfaz moderna con efectos de *glassmorphism*, gradientes vibrantes y totalmente responsiva (funciona en móviles y tablets).

## 🚀 Cómo empezar

No requiere instalación de servidores ni bases de datos complicadas. 

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, etc.).
3. ¡Comienza a cargar tus productos!

## 🛠️ Tecnologías utilizadas

- **HTML5 & CSS3**: Estructura semántica y diseño avanzado con variables CSS y Flexbox/Grid.
- **JavaScript (Vanilla)**: Lógica pura sin dependencias pesadas para una velocidad máxima.
- **SheetJS (XLSX)**: Potente librería integrada vía CDN para la generación de reportes en Excel desde el cliente.

## 📖 Instrucciones de Uso

1. **Cargar Producto**: Completa el formulario de la izquierda. El campo "Nombre" es obligatorio.
2. **Categorías**: Puedes usar el autocompletado o escribir una categoría nueva.
3. **Guardar**: Haz clic en "Agregar a la lista" para ver el producto en la tabla de la derecha.
4. **Descargar Excel**: Una vez que tengas productos en la lista, el botón "Descargar Excel" se activará. Al presionarlo, obtendrás el archivo con tus productos organizados por categorías.
5. **Limpiar**: Puedes vaciar la lista completa usando el botón "Vaciar lista" para comenzar un nuevo reporte.
